# Dreadhollow — 22 November 2026

Morvane now offers Hell, Moon and Dreadhollow. Dreadhollow is the supernatural horror environment: blood-dark water, ash-gray earth, bone-pale cliffs and black, leafless trees with twisted forks, exposed roots and faint blue-lit fissures.

Its scenery is authored 3D geometry baked through the existing renderer. The new environment uses existing tree placement, collision and paid clearing rules. It does not introduce hazards, modifiers, bonuses, resources, currencies or navigation differences. It works with the existing eleven map layouts.

The environment regression suite covers 133 world/layout, clearing, save/load and palette cases. The browser environment check covers selector contents/memory, terrain-worker pixel equality, all four scenery variants, clipping, save/load and offline launch. Current results are in environment-validation.json.
