# Elyndra environments — 22 November 2026

- Aetherland: deep plum water, chestnut soil, copper shores and dark pine forests.
- Osland: ochre-gold water, emerald soil, dark green forests and pale limestone cliffs.
- Starfall: turquoise water, lavender ground and silver-blue forests with small luminous buds.
- Elyndra offers only these three environments. Kareth retains varied, temperate, desert and arctic landscapes. Legacy/missing Elyndra environment selections render as Aetherland; the saved terrain, routes and resources remain intact.
- Every environment can be combined with the existing layouts, including Rivers, Narrows, islands and Mediterranean. Color themes do not change map generation, resource amounts, navigation, RNG or civilization bonuses.
- 133 environment regression cases pass across the three worlds, covering all eleven layouts, tree clearing, save persistence, world-specific choices and palette channels. Browser checks confirm terrain-worker pixel parity, scenery bounds, selector memory and offline compatibility. Full gameplay browser regression also passes.
